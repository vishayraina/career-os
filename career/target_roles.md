# Target Roles

## Primary Target Titles
- Staff AI Scientist / Staff ML Scientist
- Staff AI Systems Engineer / Staff Machine Learning Engineer
- Principal Machine Learning Engineer
- Applied AI Scientist / Applied ML Researcher (Speech / Audio / Multimodal)
- Founding AI Engineer (Seed / Series A with strong foreign capitalization)

## Key Responsibilities Desired
- Designing and optimizing model architectures and real-time inference systems.
- Scaling multimodal / speech / agentic pipelines.
- Technical leadership, architectural ownership, and high-impact individual contribution.

## Disfavored / Non-Target Roles
- Generic web/frontend roles with "AI" appended.
- Pure BI / data analytics / standard data engineering roles.
- Junior or non-technical project management roles.
